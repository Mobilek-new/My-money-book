# 🍞 Money Book · สมุดบัญชีขนมปัง

แอปบันทึกรายรับ-รายจ่ายภาษาไทย ธีมพาสเทลอบอุ่น ทำงานได้ 100% ในเบราว์เซอร์ ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องสมัครสมาชิก

## ✨ ฟีเจอร์
- 💰 **เงินพร้อมใช้** คำนวณอัตโนมัติหลังหักบิลค้างจ่าย พร้อมยอดใช้ได้เฉลี่ยต่อวัน
- 🧾 **บันทึกรายรับ-รายจ่าย** แยกหมวดหมู่ 15 หมวด พร้อมไอคอน
- 📊 **งบประมาณรายหมวด** พร้อม Progress Bar เตือนเมื่อใช้เกิน 80% / เกินงบ
- 🎯 **เป้าหมายการออม** ติดตามความคืบหน้าและเติมเงินออมได้
- 💳 **หนี้สิน** คำนวณจำนวนเดือนที่จะปลดหนี้จากยอดผ่อนต่อเดือน
- 🔔 **รายการประจำเดือน** แจ้งเตือนบิลใกล้ครบกำหนด / เลยกำหนด
- 🏦 **บัญชีธนาคารไทย 12 แห่ง** พร้อมโลโก้ SVG และสีประจำธนาคาร
- 📈 **รายงาน** กราฟโดนัทแยกหมวด + กราฟแท่งย้อนหลัง 6 เดือน + สรุปรายวัน/เดือน/ปี
- 💡 **วิเคราะห์พฤติกรรม** หมวดที่ใช้มากที่สุด เฉลี่ยต่อวัน เทียบเดือนก่อน
- 🌙 **โหมดมืด** และ 💾 **สำรอง/กู้คืนข้อมูล** เป็นไฟล์ JSON

## 🚀 วิธีใช้งาน
เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้ทันที หรือรันเซิร์ฟเวอร์ในเครื่อง:

```bash
git clone https://github.com/<your-username>/money-book.git
cd money-book
python3 -m http.server 8000   # เปิด http://localhost:8000
```

## 🌐 Deploy ด้วย GitHub Pages
1. Push โค้ดขึ้น repository
2. ไปที่ **Settings → Pages**
3. เลือก **Source: Deploy from a branch** → `main` / `root`
4. รอสักครู่แล้วเข้า `https://<your-username>.github.io/money-book/`
